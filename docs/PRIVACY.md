# 隐私、密钥与公开发布

## 仓库包含什么

程序源码、默认提示词、通用图像、构建配置、文档和合成测试。默认人设定义角色，不包含某位用户的经历或个人记忆。首次启动在部署电脑上新建本地数据库。

不应上传：真实聊天及其摘要、事实记忆、感情版本、模拟生活日记、学习记录、备份、SQLite 文件、API 请求响应、日志、截图中的个人内容、加密密钥文件、个人引擎配置、机器路径、`.env` 或认证凭据。

当前发布采用独立干净目录和文件白名单，不继承工作目录或个人资料目录的历史。历史开发文档即使隐藏了 Authorization，也可能包含整段真实聊天，因此不发布这些材料。

## 应用的数据流

| 场景 | 本地保存 | 发往外部 |
| --- | --- | --- |
| 未启用聊天的学习桌 | 待办、随手记、计时、统计等 SQLite 数据 | 不需要模型请求 |
| 启用聊天并发送消息 | 对话、相关记忆和状态 | 向 `api.deepseek.com` 发送默认人设、近期最多 200 条完整消息、相关记忆、感受、动机、模拟生活，以及学习概览/检索内容 |
| 后台整理 / 主动联系 / 模拟生活 | 更新事实、感受、生活与调度记录 | 运行中的引擎可能向 DeepSeek 请求整理、生成或联网；可能计费 |
| 搜索 / 网页读取 | 带来源时间的缓存 | 将关键词或网页 URL 发送给 DeepSeek 工具接口；工具服务可能访问目标网站 |
| 备份 / 导出 | 用户数据目录或自行选择的文件 | 不会自动上传到 GitHub |

提示词限制只提交必要的公开搜索词，模型生成的搜索请求仍需结合实际使用判断。开启模型功能意味着相关私人内容会离开本机；不要把不希望发送给服务商的内容交给聊天。暂停聊天或完全退出应用可停止其后台调度。

## 密钥处理

通过 Electron `safeStorage` 使用系统加密能力存放到 `companion-key.enc`。Linux 的 `basic_text` 后端和加密不可用的环境只保留本次会话，不落盘明文密钥。也可读取进程环境变量 `DEEPSEEK_API_KEY`。界面只返回是否配置和存储方式，不返回密钥值。

数据库、导出和备份**不等于加密保险箱**；密钥加密不会自动加密聊天数据库。请依赖自己的账户权限、磁盘加密和备份策略保护文件。不要把加密密钥文件放入公开仓库，它仍然是私人凭据材料。

## 发布检查

```bash
npm run check:privacy
node scripts/check-privacy.cjs --staged
git diff --cached --stat
```

检查脚本只报告文件名和规则，不打印匹配到的秘密。它拦截私人文件路径、常见密钥前缀、字面量凭据、个人主目录路径、邮箱、未知二进制和 PNG 文本/EXIF 元数据。GitHub Actions 会再次检查仓库文件。

`.gitignore` 不会移除已经跟踪的内容，模式检查也不能识别所有个人信息。提交前必须检查实际文件列表、改动、图像和 Git 提交的作者邮箱。不要通过给整个个人目录做 `git add` 来发布项目。公开 issue、截图和 Actions 日志也不要放入真实对话或密钥。

如果曾经提交真实密钥，仅从最新文件中删除并不足够：应先在服务商处撤销并更换，再处理 Git 历史。本次发布使用全新的干净历史。
