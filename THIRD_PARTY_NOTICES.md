# Source and dependency notices

The Dafeyu engine in `electron/agent/` and `electron/dafeyu-engine.cjs` is an independent implementation. This distribution does not bundle or run the former MaiBot framework, FastEmbed, BGE model or their Python environment. Compatibility code can import a user's existing local message database; no such database is distributed.

Electron/Chromium, React, Vite, TypeScript, electron-builder and other installed dependencies retain their respective licenses and notices. Packaged Electron distributions include Electron's license and Chromium third-party notices. SQLite support comes from Node/Electron.

The StudyDesk application icon and 大肥鱼 avatar are AI-generated images. The avatar draws on the community's blue-haired whale-girl design vocabulary and is not an official DeepSeek avatar. See `docs/ASSETS.md`.
